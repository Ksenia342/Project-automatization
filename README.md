## 💡 О проекте

Программа помогает вести склад и обрабатывать заказы доставки.
В ней три типа пользователей, и у каждого свой набор возможностей:

- 🧑‍💼 **Клиент** смотрит склад, оформляет и редактирует свои заказы.
- 🎧 **Оператор** следит за заказами: меняет статусы и считает стоимость.
- 👔 **Менеджер** управляет всеми данными: складом, клиентами и заказами.

Все данные хранятся в обычных текстовых файлах, поэтому программе не нужна база данных.

## ✨ Возможности

### 🔐 Авторизация и безопасность

- регистрация с проверкой уникальности логина;
- логин только из латинских букв и цифр;
- пароль вводится скрытно, вместо символов показываются `*`;
- пароли хранятся в виде хеша, а не открытым текстом;
- роль определяется по ключу доступа при регистрации;
- проверка всех числовых вводов.

### 🧑‍💼 Клиент

| Действие | Описание |
|---|---|
| 📋 Просмотр склада | Список всех товаров с количеством |
| 🔍 Поиск товаров | Поиск по ключевому слову |
| 🛒 Создание заказа | Товар, пункт назначения, количество, тариф и способ оплаты |
| ✅ Проверка остатков | Заказ не оформится, если товара на складе не хватает |
| 📜 Мои заказы | Просмотр только собственных заказов |
| ✏️ Редактирование | Изменение количества, пункта назначения и тарифа |

### 🎧 Оператор

| Действие | Описание |
|---|---|
| 📦 Просмотр склада и заказов | Общая картина по всем заказам |
| 🔍 Поиск по клиенту | Все заказы выбранного клиента |
| 🗂 Фильтр по статусу | Выбор заказов с нужным статусом |
| 🔄 Смена статуса | Обновление статуса заказа |
| 💰 Расчёт стоимости | Стоимость = количество × ставка за единицу |

### 👔 Менеджер

Менеджер работает с тремя файлами: **склад**, **клиенты**, **заказы**.
Для каждого из них доступны:

- ➕ добавление записей;
- 🗑 удаление записей по ключу;
- 👀 просмотр;
- 🔍 поиск по ключевому слову;
- 🔤 сортировка.

## 🛠 Технологии

- **C++** с использованием стандартной библиотеки (STL)
- **ООП:** наследование (`User` → `Klient`, `Operator`, `Manager`), инкапсуляция, шаблоны
- **Работа с файлами:** `fstream`, `sstream`
- **Windows API:** `windows.h`, `conio.h` для консоли и скрытого ввода пароля

## 🚀 Быстрый старт

> ⚠️ Программа работает **только на Windows**, потому что использует `windows.h`, `conio.h` и команды `cls` / `pause`.

### Вариант 1. Visual Studio

1. Создай проект **Консольное приложение C++**.
2. Добавь в него файл с исходным кодом.
3. Нажми **Ctrl + F5**.

### Вариант 2. MinGW (g++)

```bash
g++ main.cpp -o warehouse.exe
warehouse.exe
```

> Замени `main.cpp` на имя своего файла с кодом.

## 📖 Как пользоваться

1. Запусти программу.
2. Выбери **«Регистрация»** и создай аккаунт.
3. Введи **ключ доступа**: он определяет роль (клиент, оператор или менеджер).
4. После регистрации открывается меню твоей роли.
5. В следующий раз выбери **«Вход в систему»** и введи логин с паролем.

> 🔑 Ключи доступа задаются в функции `getRole()` в коде программы.

## 📁 Файлы данных

Программа сама создаёт и использует эти файлы:

| Файл | Содержимое |
|---|---|
| `DATARegistr.txt` | Логины, хеши паролей и роли пользователей |
| `sklad.txt` | Товары на складе |
| `orders.txt` | Заказы клиентов |
| `clients.txt` | Данные клиентов (ведёт менеджер) |

**Формат записи на складе:**

```text
номер | название товара | количество
```

## 🗂 Структура кода

```text
User                  ← базовый класс пользователя
├── Klient            ← клиент
├── Operator          ← оператор
└── Manager           ← менеджер

Registration          ← регистрация и вход
Human                 ← личные данные (имя, фамилия, страна)
hashing::Hash         ← хеширование паролей
```
